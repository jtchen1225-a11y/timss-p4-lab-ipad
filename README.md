## 🎯 課堂核心痛點重構升級

1. **畫筆退出與事件阻斷修復 (Robust Pen Control)**：
   - 舊版畫筆啟動後無法取消並阻礙了底層實驗操作。
   - 本版本採用獨立懸浮工具箱，配備顯目的 **【❌ 退出畫筆】** 按鈕。退出後畫布自動設置 `pointer-events: none`，立即無縫恢復手指對天平、量筒、方塊、三角板的流暢觸控拖曳。
2. **突出核心動手實驗 (80%+ 超大操作畫布)**：
   - 針對 10 吋 iPad 螢幕，去除佔空間的冗餘線上打字表單，將畫面 85% 空間全力留給核心實驗教具。
   - 大按鈕（48px+ 觸控目標）、防誤觸滑桿、大字號數值顯示，讓圍坐在 iPad 四周的 4 名組員都能清楚看見並動手操作。
3. **紙本工作紙填寫即時指南 (Paper Worksheet Guide)**：
   - 底部常駐「📄 個人紙本工作紙填寫指南」：即時提取 iPad 當前實測數據，清晰指引「第 1 題填入 [數據]」、「第 2 題算式 [公式]」、「發言人說理欄寫下 [標準金句]」。
   - 讓記錄員與全員隨時能把 iPad 的動態發現精準謄寫到各自桌面上的紙本實驗單中。
4. **iPad 輪流動手角色指針 (Turn-Taking Navigator)**：
   - 螢幕頂部清晰指示「👉 當前動手角色：🔴 操作員 ➔ 🟣 質疑員」，引導組內良性輪換，落實布魯納「動作 ➔ 圖像 ➔ 符號」認知階梯。

## 🛠️ 課堂教具工具箱

- ✏️ **畫筆批註工具**：配備【❌ 退出畫筆】按鈕、4 色彩筆（紅/藍/黃/綠）、橡皮擦、清屏。退出時完全穿透，不干擾觸控。
- 🔴 **雷射筆指引**：發光紅點，iPad 上手指滑動可清晰引導全組目光。
- 🔊 **Web Audio 觸覺合成音效**：內建天平喀嗒、落水漣漪、皮筋彈性、印章轟鳴與通關號角（離線即開即響）。
- ⛶ **全螢幕模式**：一鍵隱藏 Safari 網址列，全屏專注於操作體驗。
