### 核心教學原則：任務即刻歸零 ➔ 教師步進引導 ➔ 學生主動探究 ➔ 資優延伸拔高
1. **任務切換即刻歸零**：點擊任何任務選項（包含延伸挑戰）時，教具畫面一律清零待測，絕不直接呈現最終答案。
2. **教師引導條 (Teacher Guide Banner)**：提供教師課堂引導語與學生操作提示（第 1 步 ➔ 第 2 步 ➔ 結論揭秘）。
3. **學生操作即時反饋**：由學生動手操作推進步驟，親身體驗物理與幾何反饋，自主發現數學規律。
4. **全 11 週資優延伸探究（🚀 任務）**：
   - **W01**：跨數位自由 PK 實驗室（百萬/十萬/萬/千/百位自由對抗、7個十萬 vs 9個萬）。
   - **W02**：多數值裝袋流水線（87÷6、105÷8、148÷12、215÷45 及 20~220 自訂滑桿實驗室）。
   - **W03**：平行線間距自訂（2~8cm）與手滑偏轉 8° 反例對照實驗。
   - **W04**：隨機神秘盲盒測量與自訂破損直尺心算挑戰。
   - **W05**：二重多步運算大採購（$200 買 4 盒色筆與直尺、括號天平對抗）。
   - **W06**：轉角兩面靠牆農場（L+W 省下一半籬笆）與自訂長寬滑桿。
   - **W07**：真分數多切片 PK（2/3 vs 3/5、3/4 vs 5/8 幾何通分疊加）。
   - **W08**：8 塊方格極限變形（1×8 vs 2×4 vs 階梯形、接縫吞邊極值定理）。
   - **W09**：小數盲盒水滴 PK（0.6L vs 0.589L 陷阱題、0.25L vs 0.205L）。
   - **W10**：高階雙重補償魔術（567+198 湊整200、832-299 湊整300）。
   - **W11**：周界 24cm 面積極值探索（11×1 到 6×6 正方形面積最大定理）。
